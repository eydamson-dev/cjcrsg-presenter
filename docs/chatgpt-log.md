# ChatGPT log

Every autonomous write to the ChatGPT project `cjcrsg-presenter` is recorded here,
under the permission in `AGENTS.md`. Newest entries last. Each entry is written
before the next write.

Fields: date (UTC), action (`create_chat` or `send_message`), title, chat URL,
topic ID, purpose, status (`ok`, `unknown`, `refused`).

The daily limits count the entries for the current UTC date.
