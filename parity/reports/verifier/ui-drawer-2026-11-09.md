## The `CJCRSG_DRAWER` evidence hook

- It is gated by `cfg!(debug_assertions)` (`app.rs:142`) and reads
  `CJCRSG_DRAWER` only after that check; a release build does not run it.
- It only dispatches DOM clicks/pointer events. It cannot call Play and does not
  touch the engine, `SharedEngine` or a published `RenderState`; it can change
  local drawer state and the session file, which is UI state, not render state.
- It **does weaken what the interaction screenshots prove**. The tab clicks are
  equivalent to real clicks on visible buttons, but the `drag:` action
  dispatches `pointerdown` directly on `.drawer-top` at x=900, bypassing real
  hit-testing; the max capture therefore proves the handler works when the event
  target is the strip, not that a pointer on the 4 px bar (or the bar centre)
  starts a drag. The static appearance (labels, palette, 300/744 geometry,
  clock) is still the real rendered app. The hook is an honest workaround, but
  it cannot be used to claim the top-edge-bar gesture.
