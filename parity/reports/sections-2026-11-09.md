# Projects with sections import — 2026-11-09

Any FreeShow project that contained a section failed to import with
"references show X, which is not in the shows folder". A section is a project
item without a `.show` file, and the importer treated every reference as a show.

## What changed

`Project.entries` keeps the project's ordered item list:

```rust
pub enum ProjectEntry {
    Show { id },
    Section { id, name },
    Other { id, item_type },
}
```

- A reference that resolves to a show is imported, as before.
- A `type: "section"` without a show file becomes an ordered `Section` marker
  with its name.
- Any other non-show type (`image`, `video`, `pdf`, …) becomes `Other`, so the
  structure is not silently lost.
- A reference that claims to be a show and has no file still fails loudly — the
  old protection is intact.

`inspect` prints the result:

```text
entries   4
  section Opening (sec-open)
  section Sermon (sec-sermon)
  item    image (img-1)
```

## Measured

The fixture project (`evidence/sections/projects.json`) has two sections, one
show and one direct image item. Before this change it failed to import at all;
now:

```text
imported project "Sunday Service" -> sunday.cjcp (1 shows, 3 slides)
entries   4
  section Opening (sec-open)
  section Sermon (sec-sermon)
  item    image (img-1)
```

Raw: `evidence/sections/inspect-sections.txt`, `projects.json`.

## Tests

- sections and other items do not fail the import; order and kinds are kept;
- a section-only project imports with zero slides;
- a reference typed `show` with no file is still an error (existing test).

## What DEV-009 still is

Sections are now **data**: they survive import, save and inspect, in order. Not
implemented:

- **focus mode**, FreeShow's section-by-section presentation view;
- **section actions** (skip, loop, notes, custom actions) during navigation;
- **dividers and placeholders** as navigation behaviour rather than markers.

The engine remains linear over slides; the entries are there for the navigation
model to use when it grows one.
